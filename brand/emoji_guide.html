🎨 راهنمای «ایموجی اختصاصی» دکمه‌های ARIAMIR

تبدیل PNGهای پک به ایموجی اختصاصی تلگرام و اتصال به کد ربات — روش درستِ سال ۲۰۲۶.

✅ خبر خوب: از «۹ فوریه ۲۰۲۶» تلگرام به همه‌ی ربات‌ها اجازه داده ایموجی اختصاصی بفرستند، به شرطی که صاحب ربات (تو) تلگرام Premium داشته باشد. پس نیازی به اسم گرانِ Fragment نیست.
⚠️ دو پیش‌نیاز:
  1. صاحب ربات باید تلگرام Premium داشته باشد (برای ارسال ایموجی اختصاصی).
  2. دکمه‌ها SVG نمی‌پذیرند؛ پس از ایموجی اختصاصی (همین پک) استفاده می‌کنیم.
اگر Premium نباشد، کد خودکار به ایموجی متنی برمی‌گردد و ربات خراب نمی‌شود.

📦 محتوای پک

فایل‌های PNG شفاف ۵۱۲×۵۱۲ در پوشه brand/emoji_pack/ (روی گیت‌هاب) هستند. همه زیر ۶۴ کیلوبایت‌اند و برای آپلود تلگرام مناسب‌اند.

🚀 مرحله ۱ — ساخت پک ایموجی (با @Stickers)

  1. تلگرام را باز کن و به @Stickers برو → Start.
  2. دستور /newemoji را بفرست. (اگر نیامد، منوی ربات را نگاه کن؛ گزینه «New emoji pack» را بزن.)
  3. عنوان بده (≤۶۴ کاراکتر، ایموجی مجاز) — مثلاً «آریامیر UI».
  4. نام کوتاه بده — باید یکتا، حروف کوچک لاتین و فقط _ — مثلاً ariamir_ui_v4.
  5. به‌ترتیبِ فایل brand/upload_order.txt (همان ترتیب حروف‌الفبا) فایل‌های PNG را آپلود کن (روی دسکتاپ: drag & drop یا آیکون گیره → File؛ روی موبایل: گیره → File → چندتایی).
  6. برای هر فایل، یک ایموجی متناظر بفرست (مثلاً برای آیکون خانه 🏠).
  7. وقتی همه را آپلود کردی، دستور /publish را بفرست و تصمیم بگیر «قابل جستجو» باشد یا نه.
  8. یک لینک t.me/addemoji/… می‌گیری — پک آماده است. (تا ۳۰ دقیقه طول می‌کشد CDN لود شود.)

🛠 مرحله ۲ — گرفتن کدهای ID و اتصال به ربات

حالا کد عددی هر ایموجی را می‌گیریم و در config.ICON_IDS می‌گذاریم. اگر به‌ترتیبِ upload_order.txt آپلود کرده باشی، این اسکریپت خودکار انجامش می‌دهد:

TELEGRAM_BOT_TOKEN="<توکن ربات>" EMOJI_SET_NAME="<نام پک>" \
  python3 brand/scripts/map_emoji_ids.py

خروجی به‌صورت home=5368123456 orders=5368998877 ... است. سپس با اسکریپت دوم، src.enc را به‌روزرسانی و برای پوش آماده می‌کنیم:

SRC_KEY="<رمز src.enc>" \
  python3 brand/scripts/build_icon_ids.py home=5368123456 orders=5368998877 ...

سپس: cp src_new.enc src.enc && git add src.enc && git commit -m "🎨 ICON_IDS جدید" && git push origin main

📋 نکته‌ی مهم درباره‌ی ترتیب

چون getStickerSet ایموجی‌ها را به ترتیبِ اضافه‌شدن برمی‌گرداند، همان ترتیبِ upload_order.txt را رعایت کن تا نگاشت خودکار درست باشد. اگر ترتیب را رعایت نکردی، کافی است خروجی را با نام فایل‌ها دستی جور کنی.
