     SRC_KEY='رمز فایل‌ها' ./decrypt.sh    و برو داخل پوشهٔ decrypted
(اگر زیپ رمزدار Arsourcer را داری، بعد از بازکردن با رمز، سورس باز است.)

۱) پیش‌نیازها
────────────────────────────────────────────────────────────────
• یک VPS لینوکسی (Ubuntu/Debian پیشنهاد می‌شود) با Python 3.11+
• دسترسی SSH و اینترنت

۲) مرحله‌به‌مرحله نصب
────────────────────────────────────────────────────────────────
۱. وارد پوشهٔ پروژه شو و محیط مجازی بساز:
     python3 -m venv venv
     source venv/bin/activate
     pip install -r requirements.txt

۲. فایل تنظیمات را از نمونه بساز:
     cp .env.example .env

۳. فایل .env را با ویرایشگر باز کن (nano .env) و مقداردهی کن:

     ┌──────────────────┬─────────────────────────────────────────┐
     │ BOT_TOKEN        │ توکن ربات از @BotFather (اجباری)        │
     ├──────────────────┼─────────────────────────────────────────┤
     │ ADMIN_GROUP_ID   │ آیدی عددی گروه ادمین برای دریافت آنی    │
     │                  │ سفارش‌ها و فیش‌های واریزی؛ با -100      │
     │                  │ شروع می‌شود (اجباری)                    │
     ├──────────────────┼─────────────────────────────────────────┤
     │ ADMIN_USERNAME   │ یوزرنیم ورود به پنل با دستور /admin    │
     ├──────────────────┼─────────────────────────────────────────┤
     │ ADMIN_PASSWORD   │ پسورد ورود به پنل (قوی انتخاب کنید!)    │
     ├──────────────────┼─────────────────────────────────────────┤
     │ ADMIN_USER_IDS   │ (اختیاری) آیدی عددی کاربرانی که بدون    │
     │                  │ لاگین ادمین‌اند؛ با کاما جدا کنید       │
     └──────────────────┴─────────────────────────────────────────┘

   ⚠️ هیچ اطلاعات حساسی در بسته گذاشته نشده — همهٔ مقادیر را خودتان
   در .env تنظیم کنید.

۴. اجرای تستی (برای اطمینان):
     python -u bot.py
   اگر «آریامیر ثبت سفارش روشن شد ✅» را دیدید، با Ctrl+C بیرون
   بیایید و به مرحلهٔ سرویس بروید. دیتابیس (data/bot.db) تازه و
   صفر ساخته می‌شود.

۳) اجرای دائمی با systemd (پیشنهادی)
────────────────────────────────────────────────────────────────
۱. پوشه را به مسیر استاندارد منتقل کنید:
     sudo mv . /opt/AriamirOrders  (یا کپی به /opt/AriamirOrders)
۲. فایل سرویس را نصب کنید:
     sudo cp /opt/AriamirOrders/deploy/ariamir-orders.service /etc/systemd/system/
۳. فعال‌سازی و اجرا:
     sudo systemctl daemon-reload
     sudo systemctl enable --now ariamir-orders
۴. وضعیت و لاگ:
     sudo systemctl status ariamir-orders
     journalctl -u ariamir-orders -f

۴) نگهداری و نکات مهم
────────────────────────────────────────────────────────────────
• ورود به پنل ادمین: داخل تلگرام به ربات دستور /admin بدهید.
• 💳 تنظیمات پرداخت: در پنل، بخش «💳 تنظیمات پرداخت» — شماره کارت
  واقعی، نام صاحب کارت و بانک را تنظیم کنید (پیش‌فرض، کارت فرضیِ
  به نام ARIAMIR است و حتماً باید عوضش کنید!).
• فیش‌های واریزیِ مشتری‌ها به «گروه ادمین» می‌آید (همان ADMIN_GROUP_ID)
  — تأیید/رد با دکمه‌ها انجام می‌شود و ربات خودکار فایل پروژه +
  رمز فایل را برای مشتری می‌فرستد.
• آپلود فایل پروژه و رمز فایل: از کارت هر سفارش در پنل (📎 و 🔑).
• وضعیت کاربران: کارت هر کاربر → «📋 سفارش‌ها و وضعیت‌های کاربر».
• ریست کامل دیتابیس (از داخل پوشهٔ پروژه):  python reset_db.py
• بکاپ: کافی است فایل data/bot.db را جایی امن کپی کنید.
